# LAUNCHER — estructura organizada

## Archivos principales
- index.html → estructura/contenido de la home.
- css/base.css → variables, reset, accesibilidad y estilos globales.
- css/layout.css → header, navegación, hero y layout.
- css/components.css → cards, pasos, precios, mantenimiento, FAQ y CTA.
- css/footer.css → footer y sus responsive rules.
- js/main.js → menú móvil y animación del cohete.
- aviso-legal.html → Aviso Legal.
- politica-privacidad.html → Política de Privacidad.
- politica-cookies.html → Política de Cookies.
- legal.css → estilos compartidos de las páginas legales.
- assets/ → imágenes, logos, favicon y demás recursos.

## Recursos
Mueve aquí `Imagen2.svg`, `launchertexto.png`, `launcherblanco.png`, favicon y demás imágenes.
Después cambia sus rutas en `index.html` de, por ejemplo:
`src="Imagen2.svg"` → `src="assets/Imagen2.svg"`

## Ventaja
La home deja de tener cientos de líneas de CSS y JavaScript incrustadas en el mismo HTML. Así es mucho más fácil mantener y modificar LAUNCHER.
