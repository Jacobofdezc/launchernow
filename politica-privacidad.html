2. Qué datos podemos tratar

Dependiendo de la interacción con el sitio, LAUNCHER puede tratar datos facilitados directamente por la persona usuaria, como nombre, email, teléfono, empresa y el contenido de las consultas enviadas mediante formularios.

No deben facilitarse datos especialmente sensibles a través de los formularios de contacto salvo que LAUNCHER los solicite expresamente y exista una base jurídica adecuada.

3. Finalidades y bases jurídicas

Los datos podrán tratarse para las siguientes finalidades:

  • Responder consultas y solicitudes de información. Base jurídica: medidas precontractuales o interés legítimo, según el caso.
  • Preparar y gestionar presupuestos o la contratación de servicios. Base jurídica: relación contractual o medidas precontractuales.
  • Gestionar la relación con clientes y prestar los servicios contratados. Base jurídica: ejecución del contrato.
  • Cumplir obligaciones legales. Base jurídica: cumplimiento de una obligación legal.
  • Enviar comunicaciones comerciales cuando la persona haya dado su consentimiento o exista otra base jurídica que lo permita. El consentimiento será específico y podrá retirarse.

La base jurídica concreta dependerá del tratamiento realizado. La AEPD señala que cada tratamiento debe apoyarse en una base que lo legitime. citeturn0search6

4. Conservación

Los datos se conservarán durante el tiempo necesario para cumplir la finalidad para la que fueron recabados y, posteriormente, durante los plazos legalmente exigibles para atender posibles responsabilidades.

5. Destinatarios

Los datos no se venderán a terceros. Podrán acceder a ellos proveedores que presten servicios necesarios para el funcionamiento de LAUNCHER, como alojamiento web, correo electrónico, gestión de formularios o herramientas tecnológicas, siempre bajo las garantías y obligaciones que correspondan.

También podrán comunicarse cuando exista una obligación legal.

6. Transferencias internacionales

Algunos proveedores tecnológicos pueden tratar datos fuera del Espacio Económico Europeo. Cuando exista una transferencia internacional, LAUNCHER aplicará las garantías exigidas por la normativa de protección de datos, cuando resulten necesarias.

7. Derechos

La persona interesada puede solicitar, cuando proceda, el acceso a sus datos, su rectificación, supresión, oposición, limitación del tratamiento y portabilidad, así como retirar el consentimiento cuando el tratamiento se base en este.

Para ejercerlos puede escribir a [EMAIL], indicando el derecho que desea ejercer y aportando la información necesaria para identificar la solicitud.

También puede presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD) si considera que el tratamiento vulnera la normativa aplicable.

8. Seguridad

LAUNCHER aplica medidas técnicas y organizativas razonables para proteger los datos frente a pérdida, alteración, acceso no autorizado o tratamiento ilícito, teniendo en cuenta los riesgos del tratamiento.

9. Actualizaciones

Esta política podrá actualizarse para reflejar cambios en los servicios, tratamientos o normativa aplicable.
